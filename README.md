# 作品集

这里整理了我的软件工程、计算机图形学、虚拟现实和生成式人工智能相关项目。仓库内容以项目说明、核心源码和可审阅的工程文件为主，Unity 缓存、第三方依赖、大型模型、构建包和演示视频未纳入 GitHub。

## 项目索引

### 科研与交互

`Dialpadpast`：VR 自适应拨号盘输入系统，围绕动态键位布局、词语预测、程序化 Mesh 和交互实验展开。

### AI 与系统工程

`ComfyUI-workflow`：面向低显存设备的图像与视频生成工作流，包含模型量化、CPU 卸载、分块采样和 VAE 解码方案。

`mini-database`：Python 实现的关系数据库，包含块存储、SQL 执行、WAL 事务和崩溃恢复，并配有回归测试。

`ReviewMind_portable`：面向论文阅读与评审的本地 AI 工具，完整模型文件因体积过大未上传。

### 图形与实时渲染

`Ring-Slices-Generator`：自主开发的 Unity 程序化网格工具，用于生成和分割圆环柱体，并支持编辑器实时预览。

`BoatAttack`、`FPSSample`、`FontainebleauDemo`、`SpaceshipDemo`：基于公开 Unity 示例进行学习性复现和功能迭代，具体来源及个人拓展见各项目说明。公开仓库不重新分发不属于我的原始资源。

### Web 与联机游戏

`STTT-server`：实时联机三连棋小游戏，包含 Socket.IO 房间、服务端权威校验和三级 AI 人机模式。

`level-devil_2-Web`：Web 陷阱闯关游戏的学习性复现与扩展，新增关卡并完成服务器部署。

## 大型文件

完整 Unity 工程、构建包、模型和演示视频通过作品集网盘链接提供。GitHub 版本优先用于阅读项目说明和核心代码。
