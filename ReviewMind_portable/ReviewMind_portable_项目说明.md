# ReviewMind

> **本人原创项目**

独立设计的本地 AI 论文评审系统。上传 PDF 之后由 MinerU 解析，再交给多角色 Agent（方法论 / 实验 / 写作 / Area Chair）分别审稿并辩论，最终生成结构化评审报告，全程不需要云端算力。

整个系统的核心是多 Agent 辩论式评审架构。方法论、实验、写作三个审稿人独立打分并输出结构化意见，Area Chair 汇总分歧、主持多轮辩论，最后给出录用建议。这个设计是在模拟真实顶会的评审流程，避免单一模型视角带来的评分偏置。

PDF 解析管线用的是本地化的 MinerU 模型，提取论文全文、公式、表格和图表结构，转化成 Markdown 和 JSON 的中间表示。后续所有 Agent 的评审都基于这份结构化上下文，而不是原始的 OCR 文本，评审意见的针对性会好很多。

提示词层面给每个审稿角色设计了独立的系统提示词，包括评审维度、评分标准和输出格式。另外做了一个分歧识别机制，自动定位 Agent 之间意见冲突的段落，让辩论轮次聚焦在真正有争议的地方。

工程上，评审会话、论文解析结果、Agent 评分、辩论消息和最终报告全部进 SQLite 持久化，支持历史评审回溯和报告下载。启动脚本会自动检查 Python 环境和依赖并按需安装，run_gpu.bat 优先走 GPU 推理，没有 NVIDIA 显卡就用 run_cpu.bat 强制 CPU 模式，同一套代码覆盖两类硬件环境。
