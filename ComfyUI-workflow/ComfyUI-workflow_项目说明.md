# ComfyUI 低显存图像 / 视频生成工作流

> **本人原创项目**

面向 RTX 4060 Laptop（8GB 显存）独立设计并验证的本地 AI 图像编辑与视频生成工作流集合，让开源扩散模型在消费级笔记本上稳定运行，不依赖云端算力。

核心思路是围绕显存做文章。FLUX.2 Klein 4B 主模型采用 FP8 精度（约 4.07GB），显存占用直接减半；Qwen 3 4B 和 UMT5-XXL 两个文本编码器固定下沉到 CPU 加载，不和扩散模型抢显存，8GB 的限制下图像编辑全流程跑下来不会爆。

视频方向的难点是长度。长视频版本用 WanContextWindowsManual 把 481 帧按 81 帧窗口加 30 帧重叠分块采样，突破了单次采样的长度限制；VAE 解码阶段用 VAEDecodeTiled 按空间和时间两个维度分块，把长序列解码的显存峰值压下来，最终稳定输出约 30 秒的连贯视频。

输出层做了多格式适配，WebM（VP9）、WebP、MP4（H.264）三种格式按场景切换，预览用轻格式，成片直接出 H.264。

目录里的 outputs 是四个工作流 JSON 和对应的使用说明，覆盖单图/双参考图编辑、文生视频、首帧图生视频加镜头运动、长视频实验版四条链路。third_party_review 存放的是 Impact-Pack、Impact-Subpack、VideoHelperSuite 三个插件的源码评审记录，用于节点能力评估和依赖安全审计。

启动 ComfyUI 时建议附加 `--lowvram --reserve-vram 1.5`，VAE 解码仍然紧张就加 `--cpu-vae`，代价是解码变慢。各工作流所需模型的下载链接和放置路径写在 outputs 的说明文档里。
