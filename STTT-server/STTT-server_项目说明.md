# Strategic Tic-Tac-Toe 联机对战服务器

> **本人原创项目**

独立开发的超级井字棋（9x9 Ultimate Tic-Tac-Toe）联机对战游戏，Node.js 服务端加纯前端 Web 页面，人机对战、本地双人和在线多人实时对战三种模式齐备。

AI 是先做的部分。为 9 宫格层级棋盘设计了启发式评估函数，把小棋盘控制权和大棋盘连线威胁做加权，实现简单、进阶、困难三档 AI。困难模式通过限制搜索深度加候选步排序，强度和响应时间兼顾。

对战架构走的是服务端权威模式。所有落子由服务端统一校验合法性，包括目标小棋盘限制、重复落子、越权操作，校验通过才广播棋盘状态，客户端不做任何判定，前端篡改没有意义。

实时同步用 Socket.IO 事件驱动，createRoom、joinRoom、makeMove、restartGame 一套事件协议驱动房间状态流转。games Map 管理房间，waitingPlayers 队列做随机匹配，断线时房间状态可回收。

前端是零框架实现，原生 JavaScript（ES6+）完成棋盘渲染、回合状态机和动画反馈，拟态风格 UI 带暗色主题，音效是 Web Audio 程序化生成的，没有构建步骤，部署即用。

部署上编写了 PM2 的 ecosystem 配置支持多实例集群模式，已完成服务器部署上线，公网可以通过邀请链接直接对战。
