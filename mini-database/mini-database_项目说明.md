# Mini-DBMS 关系数据库管理系统

> **本人原创项目**

用 Python + PLY 从零实现的单机关系数据库管理系统。存储引擎、SQL 解析器、查询执行器和事务日志全部手写，支持交互式操作与 SQL 语句两种访问方式，附带一套覆盖 17 项功能的自动化回归测试，全部通过。

存储层以 4096 字节为块单位管理数据文件。表数据按字段类型（str/varstr/int/bool）做字节级序列化，块内维护记录偏移指针，模式信息持久化在 all.sch，崩溃后可从二进制残片自动识别并恢复孤立表文件。索引模块提供按字段建索引的能力，加速条件查询。

SQL 链路用 PLY 构建：词法分析把 SQL 拆成 token 流，语法分析按文法规则生成语法树，再转换成逻辑查询计划执行。支持的语句覆盖 CREATE TABLE、INSERT INTO、DELETE FROM、UPDATE SET、DROP TABLE，以及带 WHERE 条件的 SELECT。除了 SQL 入口，主控模块还保留了 7 个交互式菜单分支，可以不写 SQL 直接完成建表、插数据、条件查询、按关键字删除和更新。

事务模块是整个项目最有分量的部分，实现了一套完整的前写日志（WAL）。日志记录采用 560 字节定长格式，包含操作类型、事务 ID、表名、前后镜像和时间戳，提交前强制 fsync 落盘。事务内的插入和更新先写日志再动数据；系统崩溃后重放 wal.log，已提交事务 REDO、未提交事务 UNDO，保证数据不丢不脏。测试里专门有一项是杀掉进程后启动恢复流程，回放结果与预期一致。

工程化方面写了一个自动化测试脚本，用子进程喂输入序列的方式驱动主程序，覆盖建表、查询、增删改、全部 SQL 语句、事务插入、崩溃恢复、日志查看等 17 项，跑完输出结构化的测试报告。环境只需要 Python 3.8+ 和 pip install ply，双击入口即用。
