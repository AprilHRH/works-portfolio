# 实验 2：SQL 语句解析

## 实验目标
- 实现 DBMS 的 SQL 解析与执行
- 支持 SELECT 查询语句
- 可选实现 CREATE/INSERT/UPDATE/DELETE/DROP

## 必做 SQL 示例（缩进形式，避免嵌套冲突）
    select * from students;
    select name from students;
    select name from students where age=19;

## 选做 SQL 示例（缩进形式）
    create table courses(c_id char(20), title char(20), semester char(20), credit integer);
    insert into courses values('c01','database system','fall',3);
    delete from courses;
    update courses set semester='spring' where c_id='c01';
    drop table takes;

## 实验步骤
- 完善模块：
  - `lex_db.py`：词法分析，将 SQL 分割为 Token
  - `parser_db.py`：语法分析，构建语法树（AST）
  - `node_db.py`：定义语法树节点
  - `query_plan_db.py`：生成并执行逻辑查询计划
- 在 `main_db.py` 中：
  - 测试第 5 个分支的 SELECT-FROM-WHERE
  - 若实现选做内容，入口编号从 8 开始

## 关键技术

### 1. 词法分析（lex）
- 识别关键字：SELECT、FROM、WHERE、AND
- 识别字段名、常量、逗号等 Token

示例 SQL（缩进形式）：
    select f1,f2 from GOOD where f1='xx' and f2=5

识别出的 Token：
  - LexToken(SELECT,'select',1,0) 
  - LexToken(TCNAME,'f1',1,7) 
  - LexToken(COMMA,',',1,9) 
  - LexToken(TCNAME,'f2',1,10)  
  - LexToken(FROM,'from',1,13)  
  - LexToken(TCNAME,'GOOD',1,18)  
  - LexToken(WHERE,'where',1,23)  
  - LexToken(TCNAME,'f1',1,29)  
  - LexToken(EQX,'=',1,31) 

### 2. 语法分析（parser）
- 使用 yacc 风格规则定义语法
- 构建 AST（语法树）

示例规则：
    SFW : SELECT SelList FROM FromList WHERE Cond

### 3. 查询执行（query_plan_db.py）
- `construct_logical_tree()`：AST 转逻辑查询计划
- `execute_logical_tree()`：执行查询

### 4. 全局变量（common_db.py）
- lex 解析器
- yacc 解析器
- 全局语法树
- 查询计划树

## 实现思路
1. **词法分析**：SQL → Token  
2. **语法分析**：Token → AST  
3. **查询执行**：逻辑树访问存储数据  
4. **入口函数调用**：根据菜单选项执行对应操作
